# AI 网关模型市场价与成本治理基线

## 目的

本文档用于承接历史模型市场价与成本治理基线中仍作为长期规则的价格与成本治理语义。

---

## 1. 当前正式定位

模型市场价与成本治理当前不是 provider 适配细节，而是：

- 网关控制面与运营面的一条正式治理主线

它回答的是：

1. 模型默认价格从哪里来
2. 平台售价与近期样本如何并存
3. operator 看到的价格矩阵应如何理解

---

## 2. 当前正式价格来源

当前价格展示与成本治理应至少继续区分：

1. 平台售价
2. 近期样本窗口
3. 别名分桶
4. 价格矩阵

这几个维度不能再被压成单个“模型价格”字段。

---

- 成本治理与市场价语义

- access key 权限
- 单条 provider credential 生命周期
