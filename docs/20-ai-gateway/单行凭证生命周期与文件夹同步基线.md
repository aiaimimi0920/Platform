# AI 网关单行凭证生命周期与文件夹同步基线

## 目的

本文档用于把历史“单行凭证生命周期与文件夹同步”规则中仍然作为长期真相层的内容，收口为新的 canonical 专题。

---

## 1. 当前正式真相层

AI Gateway 真实凭证当前正式真相层仍然是：

- `gateway_provider_credentials`

每条真实凭证必须：

1. 单独一行
2. 单独生命周期
3. 单独健康度与运行时材料

---

## 2. provider account 与 provider credential 的边界

当前正式规则：

- `provider account`
  - 承载共享配置、路由 surface、共享 payload、显示模型等
- `provider credential`
  - 承载单条真实执行材料

不得再把整个凭证池打包塞进单个 `provider account`。

---

## 3. 文件夹同步的正式理解

文件夹同步当前作用是：

1. 从文件导入单条凭证
2. 把单条凭证归一到数据库真相层
3. 允许从数据库再导出回文件

它当前不改变“单行真相层”这一原则。

---

## 4. 当前正式目录结构

当前新目录结构应优先按以下层级组织：

- `<root>/<service-provider>/<provider-surface>/<credential-material-kind>/<credential>.json`

旧目录结构可继续兼容读取，但不再是首选 canonical 结构。
