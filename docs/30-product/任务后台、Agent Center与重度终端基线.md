# 任务后台、Agent Center 与重度终端基线

## 目的

本文档用于接住以下仍未完全迁移的高频旧专题：

- 个人任务后台配置
- Agent Center 与 Agent 市场一期规则
- 重度智能体对话终端

---

## 1. 当前正式定位

这三类内容当前都属于：

- 任务、能力与 Agent 市场主线

但它们各自是该主线下的细专题：

1. 任务后台配置
2. Agent Center / Agent 市场
3. 重度智能体对话终端

---

## 2. 任务后台配置

当前正式理解：

- 任务后台不是独立产品域
- 它是任务市场和能力供给的一部分
- 配置、匹配、定价、履约仍应回到 Task/Capability 主线理解

---

## 3. Agent Center / Agent 市场

当前正式理解：

- `Agent Center` 是用户侧管理与展示入口
- `Agent 市场` 是公开供给与交易语义
- 两者不能再只用“一个页面规则稿”来表示

当前在新树里的上位文档是：

- `任务、能力与Agent市场总线.md`

本文负责把旧一期规则提升成稳定专题入口。

---

## 4. 重度智能体对话终端

当前正式理解：

- 重度终端不是孤立聊天页
- 它属于 Agent 供给与执行能力的一部分
- 它与任务、proposal、交付、运行时能力不能割裂理解

因此后续若调整：

- `/chat` 终端结构
- 重度智能体 slot
- 对话式执行能力

都应同时回看：

- Agent 供给主线
- 任务与执行主线

---

- 任务后台、Agent Center、重度终端已有新的 canonical 专题
