# 历史归档文档主入口

本目录用于承接旧 `docs/analysis/`、`docs/plan/`、`docs/progress/` 中仍有保留价值的过程材料。

它的职责不是把这些过程文档重新升级成正式规则，而是：

1. 给旧过程文档一个稳定的新落点
2. 让后续删除旧 `docs/` 时，不会失去“这些过程文档到底属于什么主题”的索引
3. 保持正式规则与历史过程的边界清晰

## 当前正式边界

本目录中的文档默认属于：

- `Historical`

它们的价值是：

- 保留阶段性推理、拆解、验证与推进过程

它们当前不等价于：

- `rules/`
- `docs/10-platform`
- `docs/20-ai-gateway`
- `docs/30-product`
- `docs/40-engineering`

若历史归档与新的 canonical 文档冲突：

- **以 canonical 文档为准**
